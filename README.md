# Sunrise Dental of Eugene - Website & Design Mockups

A warm, clean, and plain website interface designed for **Sunrise Dental of Eugene**, tailored around the official sky-blue and sunrise-yellow branding.

## Live Website Features
- **Official Branding**: Sky blue (`#1eaae7`) and sun yellow (`#facc15`) color palette derived from the Sunrise Dental logo.
- **Eugene Local SEO**: Embedded `JSON-LD` local business schema for Eugene, OR with phone `(541) 555-0123` and address on River Road.
- **Direct Appointment Request**: Quick 3-field conversion card with instant confirmation response.
- **Trust Elements**: 5-Star Google Review spotlight, verified badges (Accepting New Patients, Same-Day Emergencies, Most Insurances).
- **Comprehensive Services**: Clean breakdown of routine cleanings, restorative crowns/fillings, family dentistry, and emergency dental care.
- **Design Variations Showcase**: Includes visual previews of Option A (Clean & Airy), Option B (Warm & Trust-Driven), and Option C (Direct Booking Card) for stakeholder review.

## File Structure
- `index.html` - Main responsive website
- `style.css` - Custom clean, warm styling system
- `app.js` - Interactive booking and navigation controls
- `assets/` - Official Sunrise Dental logo and design mockup images
- `zenith-dental/` - Minimalist dental concept
- `aura-smile/` - Luxury cosmetic concept
- `sunny-valley/` - Family & pediatric concept
